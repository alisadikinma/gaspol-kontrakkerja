# gaspol-kontrakkerja

Claude Code plugin that drafts Indonesian employment contracts (PKWT, PKWTT), freelancer service agreements and an IP/confidentiality attachment for PT INDUSIA. Each clause carries a cited legal basis; a blocking gate checks the draft before a PDF and DOCX are produced.

Status: scaffold and test harness only (KKJ-1 Phase A). Run the tests with `bash tests/run-all.sh`.
